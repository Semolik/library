
# Информационная система библиотеки

## Общие требования

Система должна иметь интуитивно понятный интерфейс, адаптивный дизайн и обеспечивать удобный доступ к управлению библиотечными ресурсами на любых устройствах.
Поддержка минимально необходимых версий браузеров (Chrome >= 100, Firefox >= 90, Edge >= 100, Safari >= 15).
Разделение прав доступа: администратор/библиотекарь и обычный пользователь (читатель).
Все данные хранятся в PostgreSQL с возможностью резервного копирования.

## Функциональные требования

### Со стороны администратора/библиотекаря

- Ведение и обновление каталога книг с указанием автора, названия, ISBN, места хранения (абонемент, читальный зал).
- Регистрация и управление пользователями с разграничением прав и ролей.
- Оформление выдачи и приёма книг на абонементах и в читальных залах с учётом установленных сроков.
- Контроль задолженностей: автоматическое выявление просрочек, начисление штрафов, блокировка доступа.
- Учёт случаев утери или порчи книг с назначением компенсации (штраф или замена).
- Формирование отчётов по выдаче, востребованности литературы и статусу пользователей (экспорт в PDF/Excel).


### Со стороны пользователей (читателей)

- Авторизация в личном кабинете по логину и паролю.
- Просмотр взятых книг, сроков возврата, штрафов и блокировок.
- Доступ к электронному каталогу с поиском по автору, названию, теме, ISBN.
- Просмотр истории выдач и статуса читательского билета.


## Дополнительные функциональные требования

- Поиск по каталогу с фильтрами.
- Уведомления о просрочках (email/push).
- Рейтинг книг и сортировка по популярности.
- Импорт/экспорт каталога в формате CSV.


## Нефункциональные требования

### Стек технологий

- **Frontend**: React.js
- **База данных**: PostgreSQL (Prisma ORM).
- **Аутентификация**: JWT-токены, bcrypt.
- **Деплой**: Docker, Nginx.


### Производительность и безопасность

- Время отклика API < 200 мс.
- HTTPS, CORS.

### Интерфейс

- Адаптивный дизайн для десктопа/мобайл.
- Пагинация, модальные формы, уведомления (toasts).
