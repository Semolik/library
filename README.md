# Информационная система библиотеки

## Цель проекта

Разработка информационной системы библиотеки  для автоматизации учёта читателей, управления фондами, выдачи и приёма литературы, а также контроля соблюдения правил пользования библиотечными ресурсами.

## Функциональные требования

### Со стороны уполномоченного лица (библиотекаря или администратора)

Система должна поддерживать:

- Ведение и обновление каталога книг с указанием автора, названия, ISBN, места хранения (абонемент, читальный зал).
- Регистрация и управление пользователей, с разграничением прав.
- Оформление выдачи и приёма книг на абонементах и в читальных залах с учётом установленных сроков.
- Контроль задолженностей: ведение списка читателей с просроченными книгами, начисление штрафов, блокировка доступа за нарушения.
- Учёт случаев утери или порчи книг с возможностью назначения штрафа.
- Просмотр отчётов по выдаче, востребованности литературы и статусу пользователей.


### Со стороны пользователей (читателей)

Система должна предоставлять:

- Авторизацию в личном кабинете по логину и паролю.
- Доступ к информации о взятых книгах, сроках возврата, наличии штрафов и блокировок.
- Возможность просмотра электронного каталога библиотеки с поиском по автору, названию, теме и другим параметрам.
- Подачу заявки на получение литературы через межбиблиотечный абонемент.
- Просмотр истории пользования и статуса читательского билета.

Система будет реализована как веб-приложение с разделением прав доступа.

## Технические требования

### Стек технологий

- **Frontend**: React.js.
- **Backend**: NestJS для структурированной архитектуры с поддержкой TypeScript.
- **База данных**: PostgreSQL.
- **Аутентификация**: JWT-токены.
